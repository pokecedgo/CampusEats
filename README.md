# Campus Eats (WIP)

Campus Eats is a Flutter-based application designed to simplify campus dining experiences. It provides users with features like meal swipe tracking, dining dollar management, and seamless authentication.

---

## Features

- **User Authentication**: Secure login and registration using Firebase Authentication.
- **Meal Swipe Tracking**: Keep track of your remaining meal swipes.
- **Dining Dollar Management**: Monitor and manage your dining dollars.
- **Third-Party Authentication**: Login using third-party providers.(.Net and Firebase)
- **Cross-Platform Support**: Available on macOS, iOS, Android, and more.
